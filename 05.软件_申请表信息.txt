软件全称：超声波智能辅助检测系统（UT-Analyst）

版本号：V1.0

软件分类：应用软件

发表状态：未发表

开发的硬件环境：x86-64 多核处理器，16GB 内存，512GB 固态硬盘，集成显卡，分辨率 2560×1440 的显示设备

运行的硬件环境：x86-64 处理器（2.0GHz 及以上），4GB 及以上内存，1GB 以上可用硬盘空间，支持 1440×900 及以上分辨率的显示设备

开发该软件的操作系统：Windows 11（64 位）/ macOS

软件开发环境 / 开发工具：Python 3.10，PyQt5，PyQtGraph，NumPy，SciPy，SQLite，PyInstaller，Visual Studio Code

该软件的运行平台 / 操作系统：Windows 10 / 11（64 位，可直接运行打包后的可执行程序）；macOS 与 Linux 需自行安装 Python 3.10 及以上运行环境

软件运行支撑环境 / 支持软件：Python 3.10 及以上运行环境与依赖清单中的第三方库（PyQt5、PyQtGraph、NumPy、SciPy）；打包版本自带运行环境，无需单独安装 Python，运行过程不依赖网络与云端服务

编程语言：Python

源程序量：约 9900 行（Python 源代码，含空行与注释，其中有效代码约 8300 行；不含测试用例与说明书配图脚本）

开发目的：研制一款离线运行的超声检测仿真与辅助判读软件，用一套统一的桌面工具覆盖从 A-Scan 波形监看、闸门读取、缺陷记录、标准判定到报告追溯的完整流程。检测人员可以在没有真实仪器和试块的条件下反复练习超声检测的操作与判读方法，在实际检测中借助规则化的等级判定和完整的记录链条减少人为偏差，同时也为无损检测的规程验证、教学演示和科研实验提供可重复、可复现的实验平台。

面向领域 / 行业：无损检测（NDT）、超声检测（UT）、承压设备与特种设备检验、工业质量检测、无损检测科研与教学。

软件的主要功能：软件围绕超声 A-Scan 检测的完整流程组织功能。采集环节提供开始检测、停止检测、冻结波形和单次采样操作，触发模式可在自动触发与闸门触发之间切换；波形区以深色工业示波器风格绘制原始波形、包络曲线、参考波形和峰值保持曲线，闸门线与游标可直接拖拽。三路独立闸门由起点、宽度和门限划定关注区域，自动捕捉区域内最高波峰并给出峰值幅值与触发状态，据此计算缺陷深度、水平距离、探头 K 值、分贝差值和波高比例；两路游标读取任意位置的往返时间与深度并显示差值，显示单位可在微秒和毫米之间切换。声速校准与探头零点延迟校准输入已知厚度和实测传播时间即可完成，结果可保存为文件供后续加载。

频谱分析对当前波形做快速傅里叶变换，支持矩形窗、汉宁窗、汉明窗和布莱克曼窗，显示峰值频率、峰值幅值和频率范围；数字滤波提供带通、低通和高通三种类型，采用零相位实现并可在滤波后复位；信号平均对连续多帧同位置波形求均值，平均次数 2 到 64 帧可调。统计面板汇总缺陷总数、平均深度和平均波幅，按 10mm 深度区间和 10% 波幅区间绘制分布直方图，并生成距离-波幅校正曲线。

验收判定把标准条款整理成可编辑的规则表，内置通用、GB/T 11345-2013 和 NB/T 47013.3-2015 三套判定配置，逐条给出缺陷等级、判定理由和整体结论；软件还用 6dB 落差法由 B-Scan 帧历史测量指示长度与指示高度，按底波幅值的滑动统计提示耦合不良与波动异常，把历次会话的缺陷按深度归组给出跨会话重复缺陷及其变化量，并按回波特征给出缺陷类型候选。高级分析面板支持分段距离-增益补偿（TCG）与 B-Scan、C-Scan 成像。会话、缺陷记录、报告和波形分块索引保存在本地 SQLite 数据库并支持逐帧、倍速和跳转回放；报告提供通用、NB/T 47013、GB/T 11345 和 ASME 四种模板，自动嵌入检测参数并输出波形总览图与缺陷截图，可导出为 HTML 或 PDF 并记录 SHA-256 哈希；波形数据可导出为 JSON 或 CSV 并重新载入比对。软件提供管理员、工程师、操作员和查看者四种本地角色，口令加盐存储并带登录失败锁定，关键操作写入带前序哈希链的审计日志；界面布局与常用偏好自动保存，F1 可调出快捷键一览表。

软件的技术特点：桌面端离线应用，采用 MVC 分层架构，闸门分析、信号处理、验收判定、耦合监测、缺陷跟踪和会话存储均为独立模块，便于替换与扩展；采集源通过统一接口接入仿真信号源、会话回放、模拟硬件与厂商设备适配器，便于对接真实仪器。波形绘制基于 PyQt5 与 PyQtGraph，采集与刷新由定时器驱动，支持高刷新率实时显示和多面板同步刷新；信号处理基于 NumPy 与 SciPy，数字滤波采用 Butterworth 二阶节（SOS）与零相位前后向滤波，信号平均按帧累加求均值，兼顾实时性与数值稳定性。验收判定不使用经验性的黑盒判断，而是由规则引擎按可编辑的规则表逐条给出等级、理由和整体结论，判定过程可追溯、可复核；缺陷类型提示与耦合监测同样采用规则评分，只作提示，不写入判定结论。检测会话由 SQLite 持久化，波形按分块索引存储以控制单文件体积；口令采用 PBKDF2-HMAC-SHA256 加盐存储并带失败锁定，审计日志以 SHA-256 前序哈希链串联，报告生成后记录文件哈希、签署人和签署时间，历史记录被改动时可以被检测出来。报告由同一套 HTML 模板渲染，HTML 与 PDF 输出内容一致，无需额外的排版组件。依赖均为跨平台开源库，软件不依赖网络与云端服务，可在没有网络的检测现场使用，并提供 PyInstaller 打包脚本生成免安装的 Windows 可执行程序。界面为深色工业风格，分组标题与关键读数以橙色强调，合格与不合格判定沿用绿、红两色。
