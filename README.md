# 超声波智能辅助检测系统 (UT-Analyst)

`UT-Analyst` 是一个基于 `Python 3.10+`、`PyQt5`、`PyQtGraph`、`NumPy` 的超声检测仿真软件，采用 `MVC` 架构，重点面向 A-Scan 波形监看、闸门检测、缺陷记录和报告追溯。

## 1. 当前能力概览

### 1.1 核心检测能力（P0）
- 实时采集控制：`开始检测`、`停止检测`、`冻结`、`单次采样`
- 波形辅助：`峰值保持`、`参考波形捕获/清除`
- 触发模式：`自动`、`闸门触发`
- 闸门检测：`Start / Width / Level` 三参数线性闸门
- 测量读数：双游标 `A/B`（图上可见标签）、`Δt/Δd` 实时显示
- 单位切换：`时间(us)` / `深度(mm)`，闸门输入自动换算
- 校准流程：`声速校准`、`零点校准(Probe Delay)`、校准文件 `保存/加载`
- 判定一致：有缺陷记录或当前触发即判 `不合格`

### 1.2 数据追溯能力
- 缺陷列表支持删除、清空、重编号
- 每条缺陷记录自动抓取对应波形截图
- 报告导出为 `HTML`，包含总览图 + 缺陷分项截图

## 2. 环境与启动

### 2.1 依赖环境
- Python：`3.10+`
- 依赖：`requirements.txt`

### 2.2 安装依赖
```bash
pip install -r requirements.txt
```

### 2.3 启动程序
```bash

```

## 3. 界面与控件说明

### 3.1 主界面布局
- 顶部菜单：`文件(File)`、`设置(Settings)`、`视图(View)`、`帮助(Help)`
- 工具栏：打开、保存、开始、停止、冻结、单次、生成报告
- 中央区域：
  - 上方：A-Scan 波形图（黑底、绿网格）
  - 下方：缺陷表（含 `实时` 行 + 历史缺陷行）
- 右侧控制面板（高度不足自动滚动）：
  - 参数区：增益、声程、探头频率、刷新间隔、声速
  - 采集控制区：触发模式、显示单位、冻结、单次、峰值保持、参考波形
  - 闸门区：Start / Width / Level
  - 定量区：深度、水平距离、dB 差值、波高比例
  - 游标区：A、B、Δ、Δd
  - 校准区：当前声速、零点延迟

### 3.2 波形图交互
- 右键菜单（中文）：
  - 自动缩放波形
  - 闸门复位
  - 清除峰值标记
  - 显示网格（开关）
- 闸门：
  - 两条竖线定义 `Start/End`
  - 一条横线定义门限 `Level`
- 游标：
  - 两条可拖拽竖线，标签 `A`、`B` 在图上实时显示
  - 标签内容随单位模式显示 `us` 或 `mm`

## 4. 可操作事项（建议按顺序）

### 4.1 基础检测流程
1. 点击 `开始检测`
2. 调整 `增益/声程/频率/刷新间隔/声速`
3. 点击 `应用参数`
4. 拖动闸门与门限，观察峰值标记与右侧定量结果

### 4.2 冻结与单次采样
1. 点击 `冻结` 暂停画面更新（便于精读当前波形）
2. 点击 `单次采样` 获取一帧新波形
3. 取消 `冻结` 恢复实时刷新

### 4.3 参考波形与峰值保持
1. 在稳定状态点击 `捕获参考`
2. 开启 `峰值保持` 观察包络上包络轨迹
3. 必要时点击 `清除参考`，关闭 `峰值保持`

### 4.4 触发模式
1. `自动`：每个采样周期都刷新显示
2. `闸门触发`：仅当闸门内达到触发条件时更新显示（模拟触发采样）

### 4.5 游标读数
1. 拖动波形图中的 `A/B` 游标线
2. 在右侧查看 `A`、`B`、`差值Δ`、`深度差Δd`
3. 切换 `显示单位` 可在 `us/mm` 两种读数间切换

### 4.6 缺陷记录与清理
1. 点击 `开始记录`（未开始记录时不会写入历史）
2. 触发后自动入表（带编号、深度、波幅）
3. 右键表格可 `删除选中记录` 或 `清空历史记录`
4. 也可用键盘 `Delete` 删除选中历史行（`实时` 行不可删）

### 4.7 校准流程
1. 设置 -> `声速校准`：输入实测往返时间与已知厚度
2. 设置 -> `零点校准`：输入实测时间与对应厚度
3. 设置 -> `保存校准` 或 `加载校准`（JSON）

### 4.8 报告导出
1. 先执行检测并记录缺陷
2. 点击 `生成报告` 打开预览窗口
3. 在预览窗口点击 `保存报告`
4. 输出为 `HTML`，可直接浏览器打开

## 5. 数据文件说明

### 5.1 波形数据导出
- `JSON`：保存参数 + 完整数组（time/raw/envelope）
- `CSV`：参数区 + 波形明细列

### 5.2 校准文件格式（JSON）
- `soundVelocityMps`：声速
- `probeDelayUs`：零点延迟
- `savedAt`：保存时间

## 6. 项目结构（MVC）

```text
app/
  model/
    signal_generator.py        # 信号仿真引擎
    ultrasonic_model.py        # 参数管理、帧数据生成、校准参数
  view/
    main_window.py             # 主界面、交互信号、图形显示
    report_preview_window.py   # 报告预览窗口
  controller/
    main_controller.py         # 采集流程、判定、报告、校准
main.py                        # 应用入口
```

## 7. 注意事项

- 本项目为仿真框架，当前未接入真实采集硬件。
- 报告判定规则：出现缺陷记录或当前帧触发即判定 `不合格`。
- 如果发现界面“无变化”，先检查：
  - 是否处于 `冻结` 状态
  - 触发模式是否设置为 `闸门触发` 且当前未触发
  - 是否点击了 `开始检测`
